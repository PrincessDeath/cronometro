**__Crônometro Web__**

Esse projeto simples foi feito para eu ter uma noção básica da funcionalidade do JS, quais comandos usar, como usar, em qual momento, etc...

Funcionalidades:
- **Iniciar** - começa a rodar o tempo
- **Pausar** - pausa o crônometro
- **Zerar** - reinica o tempo para zero

O que eu aprendi:
- **'setInterval'** - executa repetidamente o cod em um intervalo de tempo fixo
- **'clearInterval'** - interrompe a execução de 'setInterval'
- Lógica de controle de tempo
- Manipulação dos elementos

Como executar o projeto:
1. Baixe ou copie esse repositório
2. Abra o arquivo 'index.html' no navegador
